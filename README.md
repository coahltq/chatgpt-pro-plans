## 极速模式值不值这笔溢价

Pro 500 比 Pro 200 贵 300 美元一个月，买的唯一独占功能就是极速模式。这个功能的成本结构值得单独算一遍。

对 GPT-6 Astra 和 GPT-6.1 Sol，极速模式先按所选模型标准模式的 **8 倍速率**消耗套餐内含用量。内含用量耗尽后，再按标准模式额度费率的 **6 倍**扣你的额度余额。作为对比，非极速的快速模式消耗内含用量的速率是标准模式的 **2.5 倍**。

官方专门加了一句说明：这些倍数表示的是用量消耗速率，并不保证性能会按相应倍数提升。这句话很关键，它意味着你花 8 倍额度换来的不一定是 8 倍速度，具体快多少取决于任务类型。

所以判断标准很清楚：你每周有大量必须用极速模式跑的长任务，8 倍消耗能换来可感知的产出提升，Pro 500 的差价才可能赚回来。如果只是偶尔觉得回复慢，Pro 200 加买额度更划算。额度可以按需购买，极速模式不能单独买，这是两种完全不同的商品。

**确认你买的是哪一种。** 是“开在我自己号上的订阅”，还是“一个已经开好的账号”，这两者的售后逻辑完全不同。前者出问题看的是开通是否成功，后者看的是质保期内账号是否可用。商品页上通常写得很清楚，别跳过。

**确认为什么要选这一档。** Pro 100 和 Pro 200 之间是纯用量差别，没有功能阉割。如果你现在用 Plus 只是偶尔撞上限，升到 Pro 100 的边际收益最大；如果你每天都在跑 Codex 且经常被周额度打断，才轮得到 Pro 200。为了“以后可能会用得多”直接上 Pro 500，那 300 美元差价大概率白花。
